# Bloeisel Koffie website

A single-page static site for Bloeisel Koffie, Krugersdorp.

- `index.html` holds the whole page: markup, styles and scripts.
- `assets/` holds the images, the warm drinks video and the two fonts (Inter and Parisienne).

There is no build step. Upload `index.html` and the `assets` folder to any web host, keeping them side by side.

To preview locally, open `index.html` in a browser.
